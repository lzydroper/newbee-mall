# NewBee-Mall 系统功能清单

## 1. 商城前台（Mall Frontend）

### 1.1 首页模块
- **轮播图展示**：动态展示后台配置的广告图。
- **分类导航栏**：展示三级联动分类，支持点击跳转搜索。
- **配置商品展示**：
  - 热销商品：展示销量或人气最高的商品。
  - 新品上线：展示最新上架的商品。
  - 为你推荐：展示后台推荐的精选商品。

### 1.2 商品搜索与详情
- **关键词检索**：支持根据商品名称模糊搜索。
- **分类筛选**：根据三级分类进行精准定位。
- **排序功能**：支持按库存、价格等条件排序。
- **商品详情页**：
  - 商品多图展示（轮播）。
  - 基本信息（名称、介绍、价格）。
  - 商品详情（富文本图文展示）。

### 1.3 购物车与结算
- **购物车操作**：支持添加、修改数量、删除购物项。
- **结算页**：自动计算总金额，展示配送地址。
- **模拟支付**：集成支付宝与微信模拟支付接口。

### 1.4 用户中心
- **注册/登录**：图形验证码校验，MD5密码加密存储。
- **订单中心**：
  - 我的订单列表。
  - 订单详情查看。
  - 订单状态操作：取消订单、确认收货。
- **个人资料管理**：修改个人信息、地址维护。

## 2. 管理后台（Admin Backend）

### 2.1 仪表盘
- **统计信息**：展示系统运行的关键指标。

### 2.2 基础管理
- **轮播图管理**：支持轮播图的图片上传、链接修改、排序及CRUD。
- **分类管理**：三级分类的层级管理，支持各级分类的增删改查。

### 2.3 商品管理
- **商品维护**：
  - 全量商品列表展示。
  - 商品发布（包含富文本编辑器集成）。
  - 商品编辑与状态修改（上架、下架）。

### 2.4 配置管理
- **首页配置**：
  - 为“热销商品”、“新品上线”、“为你推荐”三个板块关联具体的商品。

### 2.5 订单与用户管理
- **订单管理**：
  - 订单详情查看。
  - 发货操作。
  - 订单状态人工干预。
- **用户管理**：
  - 注册会员列表。
  - 用户状态控制（启用/禁用）。

### 2.6 安全与设置
- **管理员登录**：独立的后台登录入口。
- **修改密码**：管理员个人密码与名称修改。
