# NewBee-Mall 系统业务流程

本系统主要包含两个大的业务板块：商城前台（用户端）和管理后台（管理员端）。

## 1. 商城前台业务流程

### 1.1 购物全流程
1. **浏览商品**：用户进入首页，可以通过分类导航、轮播图或首页推荐（热销、新品、推荐）浏览商品。
2. **搜索商品**：用户可以通过关键词搜索商品，并根据分类或排序规则进行筛选。
3. **查看详情**：点击商品进入详情页，查看商品大图、描述、价格及库存信息。
4. **加入购物车**：在详情页选择商品加入购物车。
5. **购物车管理**：用户可以在购物车页面修改商品数量、删除商品。
6. **结算下单**：从购物车发起结算，确认收货地址及商品清单。
7. **支付流程**：选择支付方式（支付宝/微信），系统模拟支付过程。
8. **订单追踪**：支付成功后，订单进入待发货状态。用户可查看订单状态、取消订单或在收货后确认收货。

### 1.2 用户账户流程
1. **注册**：新用户通过手机号/登录名进行注册，需输入图形验证码。
2. **登录**：用户通过账号密码登录系统。
3. **个人信息管理**：登录后可修改个人昵称、个性签名及收货地址。
4. **退出登录**：清除当前会话，返回登录页面。

## 2. 管理后台业务流程

### 2.1 商品与分类管理
1. **分类配置**：管理员配置三级商品分类，为商品上架做准备。
2. **商品发布**：填写商品基本信息、上传图片、编辑详情（富文本），关联对应分类。
3. **商品维护**：对已发布的商品进行修改、上架或下架操作。

### 2.2 首页配置流程
1. **轮播图管理**：上传首页轮播图，设置跳转链接。
2. **首页商品配置**：从已上架商品中筛选并配置到“热销商品”、“新品上线”、“为你推荐”三个板块。

### 2.3 订单管理流程
1. **订单审核**：查看所有用户下的订单详情。
2. **发货处理**：对已支付的订单进行发货操作。
3. **订单结案**：跟踪订单直至用户确认收货或系统自动完成。

### 2.4 用户管理
1. **用户监控**：查看注册用户信息。
2. **权限控制**：根据需要对异常用户进行封禁（修改用户状态）。
